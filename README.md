# RasterLab

## Запуск (Windows)

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```

## Возможности

- Загрузка, сведения об исходном файле, сохранение, отмена шага и сброс.
- Цвет выбранного пикселя; перевод **из любой** модели RGB/CMYK/HSL/LAB/HSV/YCbCr во все остальные.
- Яркость, насыщенность, контраст; гистограммы до/после, отдельные R/G/B.
- Серый цвет, линейная, гамма-, логарифмическая коррекция и эквализация.
- Эрозия, дилатация, открытие, закрытие, градиент.
- Резкость, смазывание в движении, тиснение, медиана, Canny и Робертс.
- Детекторы Харрис, SIFT и FAST.
- Бинаризация и дерево контуров.
- Поиск наиболее похожей пары среди 3–10 файлов.
- Видео: вычитание фона MOG2 и размытие движущихся областей, пауза и перезапуск.

Фильтры применяются последовательно. Слева — состояние до последней операции, справа — результат. Для независимых экспериментов используйте «Сбросить». Клик по любому изображению открывает конвертер цвета.

На видео первые кадры обучают модель фона. Используйте неподвижную камеру; воспроизведение без звука. Превью ограничивается шириной 960 пикселей. Обработка изображения производится в RGB 8 бит/канал; исходная глубина файла показывается отдельно.

## Проверки и воспроизведение примеров

```powershell
python -m unittest discover -s tests -v
python tools/make_examples.py
python tools/check_gui.py
python tools/build_report.py
```

Повторная генерация перезаписывает только демонстрационные файлы в `examples/`. Численные характеристики сжатых файлов могут зависеть от версии Pillow. Исходники алгоритмов — `rasterlab/processing.py`, преобразования цвета — `rasterlab/colors.py`.
